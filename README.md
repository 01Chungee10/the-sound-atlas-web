# The Sound Atlas

1600–1700년 여덟 지역의 음악을 연표, 사료, 연주와 함께 살펴보는 한국어 학습 사이트입니다. 첫 화면에서 스크롤 음악을 켜면 읽고 있는 장면에 따라 곡이 바뀝니다. 장면의 개념 실험실에서는 짧은 합성 예시를 직접 비교할 수 있습니다.

GitHub Pages는 이 저장소 루트의 정적 파일을 제공합니다. 이미지·음원의 원본, 제작자, 이용 조건은 각 사료 및 재생기의 음원 정보에 표시합니다. 사이트용 명조 글꼴은 나눔명조의 서브셋이며 라이선스는 `assets/fonts/OFL.txt`에 있습니다. 학습 메모와 완료 표시는 방문자의 브라우저에 저장됩니다.
